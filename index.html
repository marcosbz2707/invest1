Leitura correta: “pago oficial”, “contratado/adjudicado”, “ARP registrado” e “pagamento reportado” são estágios diferentes e não são somados como se fossem a mesma coisa. Para o CNPJ 47.677..., quantidade e valor por coleção vêm de NFs itemizadas quando disponíveis. Para o CNPJ 51.911..., diversas fontes públicas expõem apenas lote/grupo/objeto, sem títulos ou quantidade; nesses casos o painel mostra exatamente essa limitação. Para o CNPJ 46.786..., o levantamento atual não confirmou venda municipal, o que não prova inexistência absoluta de contratação.
